Assignment 1

Connecticut EV Registrations



This data is from Data.gov and has EV registration information from the State of Connecticut. This graph shows different vehicle types on the Y axis and the number of vehicles on the X axis. I think that this graph is a simple way of seeing the different types of EV and how popular they are.

EV Vehicles by Color in CT



This data shows how vehicle color is related to the number of registered Electric Vehicles in CT. I like how easy it is to read the data and how the green color makes the viewer think of Eco-friendly products.

Connecticut EV per Model Year



This data shows the how many EV vehicles are registered in CT by model year. I decreased the size of the labels on each bar to make them easier to read. I like this graph because it is easy to understand and has a vibrant color.

Connecticut EV Per Vehicle Category



This graph shows the number of vehicles by category. Unfortunately, the category descriptions are long. I made it easier to read by using different colors for each bar.
